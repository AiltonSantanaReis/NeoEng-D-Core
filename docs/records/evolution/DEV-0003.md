# DEV-0003 — Action Authorization dot-path canonicalization defect

Status: `OPEN_UNTIL_CS016C_ACCEPTED`  
Program: `POST_1_14_1`  
Affected stage: `EV-00 / CS017`  
Classification: `governance / action-authorization / path-canonicalization`

## Detection

CS017 was restarted from the accepted post-CS016B `main` and reached the
control commit `871f4c571f776e599c136ccbd131123003a69a77` with EV-00 in progress.
The governance workflow for that state passed and demonstrated that
`start_stage(CS017)` was authorized.

Before publishing or executing the EV-00 D-Lab harness, the intended
`stage_operation` paths were reviewed against the actual Action Authorization
implementation and `docs/changesets/017/ACTION_SCOPE.json` from the interrupted
branch.

The scope explicitly allowed:

`.github/workflows/ev00-dlab.yml`

The authorizer normalized a concrete path with:

`path.replace("\\", "/").lstrip("./")`

`str.lstrip("./")` removes leading characters belonging to the set `{'.','/'}`.
It therefore changes `.github/workflows/ev00-dlab.yml` to
`github/workflows/ev00-dlab.yml` and prevents the real allowlisted path from
matching its own allowlist.

## Immediate containment

- STOP before EV-00 product build/campaign;
- no fake path supplied to the authorizer;
- no edit to CS017 scope to hide the defect;
- no modification to runtime/product code;
- no weakening of D-Lab or evolution gates;
- interrupted CS017 branch preserved;
- EV-00 in official `main` remains `not_started`;
- `release_authorized` remains `false`.

## Root cause

The path normalization primitive was semantically incorrect. A character-set
strip was used where exact relative-prefix handling and repository-path
validation were required.

The defect was not caused by the `.github` path or by the CS017 allowlist.
Dot-prefixed path components are valid repository names and must retain their
identity.

## Impact analysis

### Product/runtime

No product execution occurred after detection. No runtime behavior, ABI,
canonical state, replay, rollback, snapshot, serialization or persistent format
is implicated by this defect.

### Governance

`stage_operation` could falsely reject a legitimate path beginning with a dot.
The defect is fail-closed in the observed direction, but it makes an explicitly
authorized operation impossible and invalidates the intended execution route.
It must therefore be corrected before EV-00 resumes.

### Security/scope

The correction must not turn malformed paths into valid paths. Absolute paths,
traversal, ambiguous components and forbidden paths remain rejected.

## Corrective action

CS016C / Amendment 1.3 must:

1. replace character-set stripping with exact canonical repository-path handling;
2. preserve `.github` and other dot-prefixed components;
3. reject absolute, traversal and ambiguous paths fail-closed;
4. add permanent `SCN-REGRESSION-003`;
5. add `EVREQ-073` and `INV-EV-029`;
6. prove previous governance 1.2 remains intact;
7. complete candidate, accepted-state, PR and post-merge CI before CS017 resumes.
